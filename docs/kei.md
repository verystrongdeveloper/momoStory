# 케이 추가

독립된 몸을 얻은 텐도 케이를 지원한다. 사용자가 추가한 SD 스프라이트 PNG 22종을 그대로 사용한다.
캐릭터 선택, 일반·인연 채팅, 스토리 등장 인물 선정, 대본 편집기, 재생·영상 추출,
라이브러리·공개 스토리 캐릭터 필터에 기존 캐릭터와 같은 경로로 연결한다.
고정 식별자는 `케이`, 표시 이름은 한국어 `케이`, 영어 `Kei`, 일본어 `ケイ`, 중국어 `凯伊`다.

## 조사와 페르소나

- [개발사 넥슨게임즈의 일본 5주년 소개](https://www.nexongames.co.kr/bbs/board.php?bo_table=people&wr_id=79): 파반느·최종편에서의 등장과 아리스와의 관계, 백발·적안의 모습을 확인했다.
- [일본 공식 학생 소개](https://x.com/Blue_ArchiveJP/status/2015621284898775451): 새 몸을 얻어 평소보다 들떠 있지만 스스로 자각하지 못한다는 소개. 직접 열람이 제한되어 [공식 게시물 전재](https://www.pttweb.cc/bbs/C_Chat/M.1769396573.A.36F)와 대조했다.
- [게임 프로필 정리](https://rose3.jp/characters/Kei): 밀레니엄·초현상특무부 소속, 아리스 돌보기·꾸미기·게임 취향 및 현재 이름을 교차 확인했다.
- [스토리·성격 정리](https://bluearchive.hatenablog.com/entry/2026/02/10/061734): 과거 Key에서 독립된 현재의 케이로 이어지는 변화, 날카로운 태클과 아리스를 돌보는 면을 참고했다. 비공식 해석이 포함된 자료다.

페르소나는 위 자료를 바탕으로 대화용으로 재구성했다. 말투 예시는 원작 인용이 아닌 창작이다.
존댓말과 직설적인 반문, 논리적인 태클, 서툰 감사와 실제 행동으로 드러나는 배려를 중심으로 한다.
아리스의 용사 말투·3인칭 자기 지칭과 구분하고, 매 대화를 화·부끄러움·과거의 비극으로 고정하지 않는다.
추가 학생에 대한 관계 설명은 출연 허가가 아니며, 스토리는 선정된 등장 인물과 기존 에셋만 사용한다.

## 공개 서버 반영

앱만 바꾸면 기존 서버는 케이 공개 스토리를 거부한다. 앱 배포 전 아래 두 항목을 함께 반영해야 한다.

1. `supabase/migrations/202610220001_add_kei.sql`을 DB에 적용한다. 기존 마이그레이션을 유지하면서 캐릭터 제약 조건에 케이를 추가한다.
2. 저장소 루트에서 갱신된 `shared/community/assets.json`과 `shared/community/validation.ts`를 포함해 `community` Edge Function을 재배포한다.

```sh
npm run community:assets
supabase db push
supabase functions deploy community --project-ref <PROJECT_REF>
```

CLI 마이그레이션 이력이 연결되지 않은 프로젝트는 SQL Editor에서 새 SQL만 실행한다.
기존 게시글이나 테이블은 지우지 않는다. 공개·필터·상세 조회는 로컬 PostgreSQL 테스트로 확인한다.
새 이미지를 포함하지 않은 구버전 앱에서는 케이 스토리의 표정을 표시할 수 없으므로 새 앱 빌드가 필요하다.

2026-10-22 연결된 공개 서버에 케이 마이그레이션을 적용하고 `community` 함수를 버전 9로 배포했다.
원격 마이그레이션 이력과 DB의 `community_posts_character_check`에 케이가 포함된 것을 확인했다.
실제 공개 게시글을 생성하지 않고, 로컬 PostgreSQL에서 공개·필터·상세 조회를 검증했다.
