# 채팅 이미지

채팅 입력란의 이미지 버튼으로 JPG, PNG, WebP를 첨부합니다. 이미지와 텍스트를 함께 보내거나 이미지만 보낼 수 있으며, 보내기 전 미리보기에서 제거할 수 있습니다. 메시지당 최대 3장, 한 장당 2MiB, 대화 전체 이미지의 base64 문자열 합계 6MiB까지 허용합니다. 한도에 도달하면 새 대화를 시작합니다.

Gemini 직접 REST 호출과 Express SDK 호출은 inlineData를 사용합니다. OpenRouter/Venice 호환 호출은 image_url의 data URL을 사용합니다. 선택한 모델이 이미지 입력을 지원해야 합니다. 이전 이미지는 대화 기록에 남아 후속 질문에서도 전달됩니다.

이미지는 웹/PC의 기존 IndexedDB와 모바일의 앱 문서 파일에 로컬 대화와 함께 보관합니다. 모바일의 기존 AsyncStorage 라이브러리는 첫 읽기에서 유지하고 이후 파일에 저장합니다. 이미지 데이터는 사용자가 선택한 AI 서비스에 전송됩니다. Supabase Storage나 테이블/컬럼 추가는 필요하지 않습니다.

이미지를 보낸 대화에는 hasImageHistory가 영구적으로 표시됩니다. 채팅 수정, 이미지/메시지 삭제, 이전 에피소드 선택, 스토리만 공개 모두 제한을 해제하지 않습니다. 새 대화를 시작하면 별도 세션이 됩니다. 공개 모달과 공개 클라이언트가 차단하며, 공유 검증기는 이미지 데이터나 이미지 이력 표시가 있는 요청도 거부합니다. 원격 검증기 반영에는 기존 community Edge Function 재배포가 필요하며 DB 마이그레이션은 없습니다. 로컬 이력을 위조한 클라이언트가 이미지 이력을 숨기는 경우를 서버에서 추적하는 기능은 없습니다.

검증: npm run test:chat-images, npm run test:chat-input, npm run test:gemini-models, npm run test:ai-providers, npm run test:community.

웹/PC 프로그램에서는 채팅 입력창에 포커스를 둔 뒤 Ctrl+V(또는 macOS의 Cmd+V)로 클립보드 이미지를 첨부할 수 있습니다. 스크린샷과 복사한 이미지 파일을 지원하고, 일반 텍스트 붙여넣기는 그대로 유지합니다. 첨부는 자동 전송되지 않으며 동일한 용량/공개 제한을 적용합니다.
