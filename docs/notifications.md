# Android 알림

설정 → 알림에서 전체 알림, 캐릭터 채팅 도착, 스토리 생성 완료, 영상 추출 결과, 메시지 미리보기를 설정한다.
전체 알림은 기본 꺼짐, 미리보기도 기본 꺼짐이다. 설정은 기기에 저장한다.
Android 13 이상은 사용자가 전체 알림을 켤 때 시스템 권한을 요청한다.
거절하거나 시스템에서 차단한 경우 시스템 알림 설정으로 이동할 수 있다.
소리·진동·배너는 시스템의 카테고리별 설정으로 관리한다.
알림 설정을 끄거나 미리보기 설정을 변경하면 기존 앱 알림도 제거한다.
백그라운드 생성 서비스의 필수 진행 알림은 별도로 유지한다.

앱 루트의 NotificationHost가 채팅 도착, 스토리 생성 완료, 영상 추출 완료·실패를 구독한다.
스토리 알림은 생성 결과를 채팅방/라이브러리에 저장한 뒤에만 보낸다. 생성 실패·초기화·기존 기록 조회에는 보내지 않는다.
스토리 생성 완료 알림은 별도 카테고리로 관리하며, 전체 알림이 켜져 있을 때 기본 활성화한다.
미리보기가 켜져 있으면 캐릭터 이름을 표시하고 대본 내용은 알림에 포함하지 않는다.
앱이 활성 상태이고 해당 채팅을 읽고 있으면 채팅 알림을 생략한다.
화면을 떠났거나 앱이 백그라운드인 경우, 실행 중인 생성 요청에서 응답이 도착하면 알린다.
알림은 카테고리마다 최신 한 건으로 갱신하며 탭하면 앱을 연다.
알림 실패는 채팅 수신이나 영상 저장을 실패로 바꾸지 않는다.

현재 구현은 기기에서 생성하는 로컬 알림이다. 앱 종료 후의 원격 푸시,
캐릭터의 선제 메시지, 알림에서 특정 대화방으로 바로 이동하는 기능은 포함하지 않는다.
추후 FCM 등 원격 수신을 추가할 때 동일한 설정과 카테고리를 적용해야 한다.
원격 푸시에는 프로젝트 등록, 기기 토큰과 서버 전송 구성이 추가로 필요하다.
이 알림 기능 자체는 영상 추출의 화면 잠금 중 실행을 보장하지 않는다.

네이티브 모듈과 POST_NOTIFICATIONS 권한이 추가되어 APK 재빌드·재설치가 필요하다.
웹·iOS·Expo Go·이전 APK에는 미지원 안내를 표시한다.
실기기에서 권한 허용/거절, 시스템 차단 후 복귀, 테스트 알림,
채팅 화면/다른 화면/화면 잠금 시 응답 도착, 미리보기와 알림 비활성화를 확인한다.
