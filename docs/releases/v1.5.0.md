## MomoStory v1.5.0

- 가로 모드가 스토리 재생 화면에만 적용되도록 수정했습니다. 설정·채팅·라이브러리는 세로로 유지되며, 스토리를 닫으면 세로 화면으로 돌아옵니다.
- Android 채팅 알림에 해당 캐릭터의 프로필 사진을 추가했습니다. 앱에서 사용하는 얼굴 구도로 표시하며, 사진은 앱에 포함되어 인터넷 연결 없이 사용할 수 있습니다. 표시 위치는 Android 버전과 기종에 따라 달라질 수 있습니다.
- 스토리 이동 버튼을 캐릭터 이름 없이 ‘인연 스토리로’로 정리했습니다. 다른 언어의 버튼 문구에서도 이름을 제거했습니다.
- 화면 방향 설정 안내와 사용 방법을 실제 동작에 맞춰 갱신했습니다.

Android versionCode: 23
