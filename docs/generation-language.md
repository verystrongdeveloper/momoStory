# 생성 언어

설정의 한국어/English/日本語/中文 선택은 새로 생성하는 먼저 말 걸기, 채팅 응답,
인연스토리 제목·대사·나레이션·선택지·화자 이름·학교/부서 표기에 적용된다. 中文은 간체 중국어다.

`shared/prompts/generationLanguage.js`의 공통 규칙을 직접 REST 호출과 Express의
Gemini 시스템 지시에 추가한다. 페르소나와 대본 형식은 유지하고 표시할 내용의 언어만 지정한다.
대본 명령어, 내부 캐릭터 식별자, JSON 키, 에셋 파일명은 번역하지 않는다.
화면에 표시되는 화자 이름은 선택 언어로 쓰며, 출연 허용 여부는 원래 캐릭터 식별자로
확인한다. 알려진 한국어 이름과 소속이 대본에 남으면 선택 언어 표기로 보정한다.
예: 호시노 → Hoshino / ホシノ / 星野, 대책위원회 → Foreclosure Task Force / 対策委員会 / 对策委员会.
제목 명령은 `타이틀 :`과 `title :`을 모두 지원하며, 한국어 외 생성에서는 `title :`을 사용한다.

각 생성 요청을 시작할 때 언어를 고정한다. 생성 도중 설정을 변경해도 진행 중인
스토리의 기획·대본 언어는 섞이지 않으며 다음 요청부터 새 언어가 적용된다.
Express의 SDK 세션은 시스템 지시가 바뀌면 대화 기록을 유지한 채 다시 만든다.
직접 REST 경로도 기존 대화 기록을 유지하며 매 요청에 현재 언어 지시를 전달한다.

기존 라이브러리 저장본과 이미 표시된 대화는 자동 번역하거나 덮어쓰지 않는다.
대사 전체의 언어 준수는 프롬프트로 유도한다. 이름/소속 보정 외에 출력 전체를 사후 번역하지는 않는다.

`npm run test:language`는 유료 API 호출 없이 모의 응답으로 네 언어의 직접/서버 경로,
설정 변경, 문맥 유지, 모델 재시도, 명령어 보존 및 일·중문 채팅 문장 분리를 검증한다.
