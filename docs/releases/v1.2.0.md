## MomoStory v1.2.0

### 주요 변경 사항

- 후부키를 플레이 가능한 캐릭터로 추가했습니다. 전용 성격·말투와 표정 15종을 적용하고, 대화·인연스토리·대본 편집·영상 추출에 연결했습니다. 한 줄 소개는 `커피 with 도넛!`입니다.
- 후부키 스토리를 아카이브에 공개하고 캐릭터별로 조회할 수 있습니다. 공개 서버의 캐릭터·표정 검증과 DB 제한도 반영했습니다.
- 설정에 선생 모드와 설명을 추가했습니다. 순한맛은 배려와 부드러운 유머, 매운맛은 채팅에서 보여 준 성격에 따른 능청스러운 맞받아치기와 엉뚱한 장난을 강조합니다. 자동 저장되며 다음 스토리 생성부터 적용됩니다. 성적 수위를 높이는 설정은 아닙니다.
- 직접 선택하는 Gemini 모델 목록을 `Gemini 4 Argon`, `Gemini 3.8 Flash`, `Gemini 3.1 Flash-Lite`로 정리했습니다. 자동 선택의 기존 Flash 탐색·전환 정책은 유지합니다. 이전 구형 모델 선택은 자동 선택으로 전환됩니다.
- 생성 스토리의 등장 인물을 메인 1명과 중복 없는 추가 인물 최대 2명으로 제한했습니다. 선정되지 않은 화자와 표정을 정리하여 인원 초과로 공개가 거부되는 문제를 수정했습니다.
- 영상 파일 크기 상한을 150MiB에서 512MiB로 늘렸습니다. 실제 출력이 한도를 넘으면 비트레이트를 낮춰 최대 2회 재시도하며, 해상도와 전체 내용은 유지합니다. 재시도 시 인코딩 진행률은 다시 시작합니다.
- 스토리 생성 분량은 기존 약 300줄 목표를 유지합니다. 영상 추출의 기존 10분 제한도 유지됩니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.2.0_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 12)
- 후부키 이미지와 영상 렌더러 변경을 적용하려면 새 버전으로 업데이트해 주세요. 기존 버전에서는 후부키 공개 스토리의 이미지가 표시되지 않을 수 있습니다.
- 영상 추출 중에는 앱을 실행 상태로 유지해 주세요. 화면 잠금·앱 종료·다른 앱 전환 후의 추출 지속은 보장하지 않습니다. 큰 영상의 추출 가능 여부는 기기 메모리와 인코더 지원에 따라 달라집니다.
- 생성 AI의 특성상 모드별 반응과 대본 분량을 항상 동일하게 보장하지는 않습니다.
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요하며 모델별 요금과 사용 한도가 적용됩니다.
