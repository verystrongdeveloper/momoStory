## MomoStory v1.3.0

### 주요 변경 사항

- 케이를 플레이 가능한 캐릭터로 추가했습니다. 전용 페르소나와 표정 22종을 적용하고, 캐릭터 선택·일반 채팅·인연스토리·대본 편집·영상 추출에 연결했습니다.
- 케이 스토리를 아카이브에 공개하고 캐릭터별로 조회할 수 있습니다. 한국어·영어·일본어·중국어 화자와 표정을 검증하며, 공개 서버의 DB 제한과 검증 함수에도 반영했습니다.
- 라이브러리 검색 영역을 넓혀 검색 입력란이 좁아지는 문제를 개선했습니다. 모바일에서는 검색란을 캐릭터 선택 아래로 배치하고, 캐릭터 선택 버튼의 최소 폭과 터치 높이를 늘렸습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.3.0_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 13)
- 케이 표정을 표시하려면 새 버전으로 업데이트해 주세요. 기존 버전에는 케이 이미지가 포함되어 있지 않습니다.
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.

### 검증

- 프롬프트·표정 22종·4개 언어 화자 및 선택지 검증
- 로컬 PostgreSQL을 통한 케이 스토리 공개·필터·상세 조회 검증
- 공개 클라이언트·UI, 대본 편집기, 생성 언어, 영상 타임라인·연출·에셋 테스트 통과
- 웹 프로덕션 빌드 통과
