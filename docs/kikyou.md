# 키쿄 추가

2026-10-26. 기본 교복의 키류 키쿄를 캐릭터 선택과 프로필, 일반 채팅과 인연 스토리,
스토리 편집·재생·영상 추출 및 공개 스토리 검증에 연결했다.

## 에셋과 표시

사용자가 추가한 표정 17종은 `assets/images/kikyou/kikyou_*.png`의 이름과 내용을
그대로 사용한다. 모든 이미지의 실제 크기인 409×610을 스프라이트 비율에 반영했다.
프로필에는 미소 이미지를 얼굴 중심으로 확대해 사용한다.
한국어·영어·일본어·중국어 이름과 상태 메시지, 화자와 소속 이름을 등록했다.
대본 편집기의 표정 목록에는 키쿄 그룹을 추가했다.

각 표정의 눈썹·입매·홍조·식은땀·음영 차이를 설명으로 등록하여 분노, 짜증,
침울함, 괴로움, 걱정, 난처함과 두 종류의 삐침을 구분한다.

## 페르소나 참고

- [블루아카 유틸 한국어 프로필](https://blue-utils.me/student/kikyou?lang=ko):
  백귀야행 2학년, 백화요란의 작전참모, 논리와 이성을 중시하는 판단,
  승리보다 아군의 안전을 중시하는 성격, 실뜨기·병법서·햇볕 쬐기 취향을 확인했다.
- [키류 키쿄 팬 위키](https://dark.namu.moe/w/%ED%82%A4%EB%A5%98%20%ED%82%A4%EC%BF%84):
  동료와 선생을 향한 경계와 신뢰, 무덤덤한 태도와 상냥한 내면의 해설을 참고했다.
- [공식 키쿄 음원 안내](https://forum.nexon.com/bluearchive/board_view?board=1018&thread=3327893):
  보너스 트랙 제목에서 '선생님' 호칭과 반말 조합을 확인했다.
- [일본어 수영복 음성 전사](https://bluearchive.fandom.com/wiki/Kiryuu_Kikyou_%28Swimsuit_ver.%29/Audio):
  담백한 반말과 가까이 머물고 싶은 마음을 표현하는 호흡만 참고했다.
  수영복 전용 상황과 복장은 기본 교복 페르소나에 넣지 않았다.

프로필·위키·음성 전사는 팬 자료이며, 공식 한국어 대사 전체를 직접 확인한 것으로
표시하지 않는다. 선생에게 쓰는 '선생님' 호칭과 차분한 반말, 직설적인 판단과 행동으로
드러나는 배려를 대화 지침으로 작성했다. 예시 대사는 원작 인용이 아닌 새 문장이다.
백화요란이 활동하는 현재 일상을 기준으로 하고, 매번 해산 갈등을 재연하거나
고양이 흉내·질투·독설로 모든 반응을 고정하지 않도록 했다.

## 검증과 운영 반영

표정 17종의 실제 파일·크기·투명도, 채팅과 스토리 페르소나 공유, 4개 언어 화자와
선택지, 로컬 PostgreSQL의 공개·캐릭터 필터·상세 조회를 검증했다.
프롬프트, 생성 결과 검증, 커뮤니티, 스프라이트, 편집기 및 영상 연출 테스트가 통과했다.
전체 타입 검사에서는 이전 검사와 같은 `StoryAssetPanel.tsx`의 웹 `position: fixed`와
`StoryLibraryList.tsx`의 `dataSet` 타입 오류 4건이 남아 있다.

공개 아카이브 운영 반영에는 유우카 마이그레이션 다음에
`supabase/migrations/202610260002_add_kikyou.sql`을 적용하고, 갱신한
`shared/community/assets.json`·검증기를 포함하여 `community` 함수를 배포해야 한다.
운영 DB·함수 배포와 앱/웹 빌드는 이번 작업에서 실행하지 않았다.
