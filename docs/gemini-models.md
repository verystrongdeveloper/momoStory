# Gemini 모델 선택

설정의 API 키 입력란 아래에서 `자동 선택` 또는 특정 Gemini 텍스트 모델을 선택한다. 선택값은 기기에 저장되며 다음 요청부터 적용된다. 모델 변경 시 대화 기록과 저장한 스토리를 초기화하지 않는다. 인연스토리의 인물 선정과 대본 생성은 요청을 시작할 때 선택한 모델 설정을 함께 사용한다.

모델 목록은 [Google models.list API](https://ai.google.dev/api/models#method:-models.list)에서 입력한 키로 조회한다. 현재 앱에는 최신 일반 텍스트 생성 모델인 `gemini-4-argon`, `gemini-3.8-flash`, `gemini-3.1-flash-lite`만 표시한다. 응답의 모든 페이지를 조회하며, 목록 새로고침 버튼으로 사용 가능한 모델을 다시 확인할 수 있다. 조회 결과는 키별로 메모리에 10분간 보관하며 키를 URL이나 로그에 넣지 않는다. 이전 버전에서 저장한 구형 모델 선택은 자동 선택으로 전환한다.

자동 모드는 정식 Flash 모델을 우선하며, 최신 버전부터 시도한다. 같은 목록에서는 직전 성공 모델을 먼저 사용한다. 429·503은 다른 Flash 모델로 전환하고, 404·410은 목록을 한 번 갱신하면서 다른 모델을 시도한다. 목록 조회 장애 시 기존 앱의 Flash 후보 목록을 사용한다. 자동 모드에서 Pro 계열로 전환하지 않는다. 이 자동 선택 정책은 설정 화면에 표시하는 수동 선택 모델 수와 무관하다.

특정 모델을 선택하면 그 모델만 호출한다. 해당 모델이 종료되거나 사용 한도를 초과하면 오류를 표시하며 다른 모델로 임의 전환하지 않는다. 모델 목록에 표시되어도 실제 호출 권한·지역·요금·할당량은 Google 설정에 따라 달라질 수 있다.

설치 앱의 직접 호출과 웹의 Express 요청 모두 같은 선택 정책을 적용한다. Express 사용 시 클라이언트와 서버 변경을 함께 반영해야 한다.

검증: `npm run test:gemini-models`, `npm run test:language`, `npm run test:chat-input`. API와 SDK를 모의 처리하며 실제 유료 생성 요청은 하지 않는다.
