# 메시지 응답 취소

서버의 채팅 응답을 기다리는 동안에만 입력창 옆에 ‘응답 취소’를 표시한다.
응답을 수신하면 취소 버튼을 숨기며, 말풍선 출력 중에는 취소할 수 없다.
이전 취소 버튼의 콜백을 호출해도 이미 시작된 말풍선 출력은 계속된다.
취소하면 전송한 메시지와 이전 대화는 유지하고 응답 대기 타이핑 표시를 제거한다.
입력을 즉시 다시 허용하며 늦게 도착한 이전 응답은 현재 요청 상태를 바꾸지 않는다.
작업 상태와 취소 컨트롤러는 채팅 세션에 보관하므로 다른 화면에 갔다 돌아와도 취소할 수 있다.
기존 스토리 생성/채팅 초기화 요청은 이 취소 버튼의 대상이 아니다.

AbortSignal을 직접 Gemini 요청과 Express 요청에 전달한다. Express는 응답 연결 종료 시
상위 Gemini SDK 요청도 취소하고 미확정 응답을 대화 기록에 넣지 않는다.
서버 SDK가 자체 기록 배열을 변경하므로 확정된 기록은 별도 복사본으로 유지한다.
취소 후 다음 요청에는 화면에 남아 있는 대화만 컨텍스트로 전달한다.
Android 백그라운드 생성 서비스는 요청 취소 시 늦은 네트워크 완료를 기다리지 않고 해제한다.

앱 변경 적용 외에 웹용 Express 서버도 재시작/재배포해야 상위 요청 취소가 적용된다.
검증: `npm run test:chat-input`, `npm run test:gemini-models`, `npm run test:background-generation`.
