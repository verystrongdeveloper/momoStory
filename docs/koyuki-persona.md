# 코유키 페르소나 조사·작성 근거

확인일: 2026-10-24. 기본 교복, 세미나 복귀 이후의 코유키를 기준으로 한다.

프로필 한 줄 소개는 [블루아카 유틸의 게임 데이터](https://blue-utils.me/student/koyuki)의 모모톡 상태 메시지를 한국어·영어·일본어·번체 중국어로 각각 확인해 `constants/characters.ts`의 `status`와 `displayStatus`에 반영했다. 팬이 작성한 소개문이나 임의 번역으로 대체하지 않았다. 자료 사이트 자체는 비공식 게임 데이터 정리 사이트다.

## 자료와 확인 범위

- [공식 학생 소개 게시물](https://x.com/Blue_ArchiveJP/status/1632214513197137920): 원문 직접 열기는 403으로 실패했다. [소개 내용을 인용한 동시기 기사](https://gamebiz.jp/news/365548)와 [학생 소개 인용 자료](https://pringli.tistory.com/722)에서 세미나 복귀, 암호 해독 재능과 자각의 부재를 교차 확인했다. 직접 읽은 공식 페이지로 표시하지 않는다.
- [Blue Archive Utils 학생 데이터](https://blue-utils.me/student/koyuki): 밀레니엄 1학년·세미나, 나이·생일·키·취미, 한국어 소개를 확인했다. 게임 데이터를 정리한 비공식 사이트다. 운 시험을 반복하며 실패에도 쉽게 포기하지 않는 성격을 반영했다.
- [일본어 캐릭터 호칭표](https://bluearchive.wikiru.jp/?cmd=read&page=%E3%82%AD%E3%83%A3%E3%83%A9%E5%91%BC%E7%A7%B0%E8%A1%A8): 팬 전사 표에서 유우카·노아를 선배로 부르는 관계를 확인했다. 일본어 호칭과 한국어 공식 번역은 구분한다.
- [캐릭터·스토리 정리](https://w.atwiki.jp/aniwotawiki/pages/57056.html): 재능의 직감성, 통제할 수 없는 운에 대한 흥미, 변명과 선배 앞의 당황, 선생과 함께 놀려는 태도를 참고했다. 팬의 평가·추측·취소선 농담을 공식 설정으로 채택하지 않는다. 특히 능력에 대한 장문의 심리 해석을 확정된 속마음으로 넣지 않았다.
- [공식 소개 인용 및 이벤트 정리](https://rojiuragame.com/2023/10/04/%E3%80%90%E3%83%96%E3%83%AB%E3%83%BC%E3%82%A2%E3%83%BC%E3%82%AB%E3%82%A4%E3%83%96%E3%80%91%E3%82%AD%E3%83%A3%E3%83%A9%E3%82%AF%E3%82%BF%E3%83%BC%E7%B4%B9%E4%BB%8B%E3%80%9C%E3%80%8C%E9%BB%92%E5%B4%8E/): 과거 추방 상태와 복귀 이후를 구분하고, 선생에게 재미를 공유하는 면을 보조 확인했다. 이벤트 상세를 매 대화의 전제로 삼지 않는다.
- [보이스 정리 페이지](https://bluearchive.fandom.com/wiki/Kurosaki_Koyuki/Audio)는 직접 열기에 실패했고 검색 결과에도 다수 항목의 전사가 없었다. 전체 음성을 청취했거나 한국어 공식 대사집을 검증했다고 주장하지 않는다. 한국어 말투와 예시는 자료의 태도·호칭을 대화 생성용으로 해석해 새로 작성했다.

## 대화 지침으로 옮긴 판단

- 암호 해독 재능과 좋은 운은 별개다. 능력 때문에 모든 추첨에서 이기거나 모든 종류의 문제를 해결하지 않는다.
- 장난·변명·재도전하는 면을 살린다. 늘 착한 학생으로 순화하거나, 매번 악의적으로 타인을 이용하는 인물로 만들지 않는다.
- 발랄한 존댓말을 기본으로, 들뜸·자신감·당황·진심의 속도를 다르게 적었다. 웃음과 울음만 반복하는 대화를 방지한다.
- 선생과는 함께 놀고 의지하며 작은 고마움을 표현할 수 있다. 기본 관계를 연애나 복종으로 고정하지 않는다.
- 선배들과의 관계는 말투와 판단의 배경이다. 장면에 없는 학생을 마음대로 등장시키지 않는다.
- 팬 밈, 실제 서비스 해킹 사건, 2차 창작의 폭력·연애 설정은 채택하지 않았다.

## 적용 범위와 다음 연결 지점

`shared/prompts/personas.js`에 코유키 항목을 추가했다. 채팅·스토리 프롬프트가 이를 함께 읽는다. 이후 캐릭터 추가 요청에 따라 선택 목록, 프로필, 14종 표정과 설명, 스프라이트 비율, 4개 언어의 이름·화자 매핑, 아카이브 검증 목록까지 연결했다. 기존 PNG 파일명과 원본 이미지를 그대로 사용한다.

운영 아카이브에서 코유키를 공개하려면 `supabase/migrations/202610240002_add_koyuki.sql` 적용 및 변경된 공유 검증·에셋 목록을 포함한 `community` Edge Function 재배포가 필요하다.

2026-10-24 사용자 요청에 따라 연결된 `momoStory` 운영 프로젝트에 재공개 갱신 마이그레이션 `202610240001`과 코유키 허용 목록 `202610240002`를 적용했다. 공유 검증기와 에셋 목록을 포함한 `community` 함수를 버전 10으로 배포했고 ACTIVE 상태와 원격 마이그레이션 이력 일치를 확인했다.

운영 DB의 롤백할 트랜잭션 안에서 신규 공개, 동일 내용 재요청, 수정 후 같은 게시글 ID 갱신, 좋아요·댓글·조회수·최초 공개일 보존, 코유키 필터와 상세 조회를 검증했다. 검증용 사용자·게시글·반응·횟수 기록은 모두 롤백하여 공개 목록에 남기지 않았다. 배포된 HTTP 엔드포인트의 CORS 응답과 인증 없는 요청의 401 차단도 확인했다. 실제 앱의 사용자 세션으로 공개 버튼을 누르는 검증과 앱 릴리즈는 이번 서버 반영에 포함하지 않았다.

사용자가 변경한 `koyuki_crying_hit_by_yuuka.png`를 포함하여 현재 이미지 파일명은 유지했다. 해당 파일명은 특정 표정 구분이지, 모든 울음 장면에 유우카가 등장해야 한다는 지침이 아니다.

검토용 상황: 평범한 인사 / 음식 취향 / 추첨 실패 / 암호 해독 도움 / 장난이 들킨 상황 / 진지한 칭찬 / 선생이 지친 상황. 실제 모델 출력 평가는 별도이며 프롬프트 조립 검사만으로 대화 품질을 보장하지 않는다.
