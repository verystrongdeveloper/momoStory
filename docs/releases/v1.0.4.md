## MomoStory v1.0.4

### 주요 변경 사항

- Android APK에 포함된 이미지 리소스를 읽는 방식을 수정해 영상 추출 초기 실패를 보완했습니다.
- 영상 준비·생성·저장 단계의 오류 메시지를 구분했습니다.
- 설정에 현재 버전과 업데이트 확인, 새 버전 다운로드 페이지 연결을 추가했습니다. 웹의 오래된 버전 표시도 수정했습니다.
- 스토리 배경 변경 시 페이드아웃·페이드인을 적용하고 전환 중 대화창과 선택지를 숨깁니다. MP4 추출에도 동일하게 적용됩니다.
- 일반 대사 진행 시 대화창이 깜빡이는 문제를 수정했습니다.
- PC 프로그램과 웹에서 스페이스로 문장 완성·다음 대사 진행을 지원합니다.
- 스토리 대화창의 텍스트 선택을 방지하고 키보드 입력 시 나타나던 포커스 테두리를 제거했습니다.
- AI 스토리 프롬프트에 애니메이션 4종의 의미와 사용 규칙, 실제 효과음 39개·감정 아이콘 4개 목록을 추가했습니다. 새로 생성하는 스토리부터 적용됩니다.

### 다운로드

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.4_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 5)

Gemini API 키는 포함하지 않습니다. 설치 후 설정에서 본인의 키를 입력해 주세요.
Android의 다운로드 폴더 직접 저장 기능은 APK 전용 네이티브 모듈을 사용하므로 Expo Go에서는 테스트할 수 없습니다.
