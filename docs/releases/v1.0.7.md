## MomoStory v1.0.7

### 주요 변경 사항

- 최초 실행 시 약관 동의보다 먼저 언어를 선택할 수 있습니다. 기본 언어는 영어이며 약관도 선택한 언어로 표시합니다. 기존 언어 설정은 유지됩니다.
- 앱 실행 시 최신 정식 버전을 자동 확인합니다. 새 버전이 있을 때만 다운로드 안내를 표시하며 최신 버전이거나 확인에 실패하면 팝업을 띄우지 않습니다.
- 캐릭터가 답변을 준비하거나 문장별로 출력하는 동안 메시지 입력과 전송을 막습니다.
- 캐릭터별 진행 중인 채팅과 입력 초안을 앱 실행 중 임시 보관합니다. 다른 화면이나 캐릭터로 이동해도 유지하며, 화면을 나간 동안 도착한 답변도 해당 캐릭터에 보관합니다.
- 캐릭터 목록 오른쪽에 안 읽은 메시지 수를 표시합니다. 해당 채팅을 열면 읽음 처리하며, 입력 중 표시와 사용자 메시지는 제외합니다.
- 채팅 새로고침으로 해당 캐릭터의 채팅과 AI 대화 기록만 초기화할 수 있습니다. 모바일에서는 상단 분홍색 바 오른쪽의 새로고침 아이콘을 사용합니다.
- 인연 스토리 생성·저장 완료 후 해당 캐릭터의 임시 채팅을 비우고 추가 전송을 막습니다. 새 대화는 채팅 새로고침 후 시작할 수 있습니다. 생성·저장 실패 시에는 채팅을 유지합니다.
- 인연 스토리가 최근 채팅을 반복하지 않고 마지막 답변 이후의 새 사건으로 이어지도록 기획·작성 프롬프트를 보완했습니다.
- 나레이션·선택지에서도 표정 아이콘, 움직임과 효과음을 지원합니다. 여러 연출 블록과 등록된 표정 이름의 확장자 생략도 허용합니다.
- 커뮤니티 게시글 카드에 전체 댓글 수를 표시합니다. 댓글 삭제와 목록 복귀 시 변경된 수를 반영합니다.
- 휴대폰에서 효과음을 바꾼 뒤 미리듣기가 실패할 수 있던 재생기 처리 오류를 수정했습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.7_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 8)
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.
- 임시 채팅과 안 읽음 표시는 앱 실행 중에만 유지됩니다. 앱 종료나 브라우저 전체 새로고침 후 보존되는 영구 저장 기능은 아닙니다.
- 휴대폰의 효과음 미리듣기 수정은 새 APK 설치 후 적용됩니다. 실제 단말의 재생 상태는 설치 후 확인해 주세요.
