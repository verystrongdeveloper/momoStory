## MomoStory v1.4.4

- 영상 추출 진행 표시를 화면 아래 별도 영역으로 옮겨 화면 이동 버튼과 스크롤을 가리지 않도록 했습니다. 앱 안에서 화면을 이동해도 추출은 계속됩니다.
- Android 설정에 알림 받기, 캐릭터 채팅 도착, 스토리 생성 완료, 영상 추출 결과, 메시지 미리보기와 테스트 알림을 추가했습니다. 읽고 있는 채팅은 알리지 않으며 스토리는 생성·저장 성공 후에 알립니다.
- 메시지 응답 대기 중에 ‘응답 취소’를 누를 수 있습니다. 취소 후 바로 다시 입력할 수 있으며 늦게 도착한 응답은 무시합니다. 말풍선 출력이 시작된 뒤에는 취소 버튼을 표시하지 않습니다.
- 인연스토리 생성 직후에는 생성 버튼을 숨깁니다. 새 메시지를 보내 캐릭터 응답까지 받아야 다시 표시되며, 저장된 채팅방을 다시 열어도 동일하게 적용됩니다.
- 아카이브에 ‘내가 공개한 게시물’ 필터를 추가했습니다. 제목 검색, 캐릭터 선택, 정렬과 함께 사용할 수 있습니다.
- 웹·Windows 프로그램에서 첫 선택지의 글꼴이 잠깐 바뀌던 문제를 수정했습니다. 글꼴 데이터를 미리 로드하고 실제 준비가 끝난 뒤 표시합니다.
- 코유키의 놀란 표정 이미지를 조정했습니다.

### 서버 적용 안내

- 내 게시물 필터에는 `supabase/migrations/202610250001_community_my_posts.sql` 적용과 `community` Edge Function 재배포가 필요합니다. 이번 앱 릴리즈 워크플로는 Supabase를 자동 배포하지 않습니다.
- 웹 요청 취소를 Gemini 요청까지 전달하려면 변경된 Express 서버를 재시작 또는 재배포해야 합니다.

### 알림 지원 범위

- Android 기기에서 실행 중인 작업의 로컬 알림을 지원합니다. 앱 종료 후 서버에서 보내는 원격 푸시는 포함하지 않습니다.
- 영상 추출의 화면 잠금·다른 앱 전환 중 지속 실행은 이번 버전에서 보장하지 않습니다.
