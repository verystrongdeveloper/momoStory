## MomoStory v1.4.0

### 주요 변경 사항

- 대화 세 쌍 뒤 입력이 멈추던 제한을 없앴습니다. 원하는 만큼 대화하고, 한 쌍 이상 대화한 뒤 원하는 때 스토리를 생성할 수 있습니다.
- 라이브러리 카드가 이어서 대화할 수 있는 독립된 채팅방이 됩니다. 기존 저장본도 그대로 열 수 있습니다.
- 대화 중 스토리를 생성하면 해당 위치에 인연 스토리 버튼이 남고, 그 아래로 채팅을 이어갈 수 있습니다. 생성하거나 감상한 뒤에도 대화가 초기화되지 않습니다.
- 이전 채팅과 생성된 스토리를 참고해 다음 대화와 스토리를 이어갑니다. 같은 학생의 서로 다른 채팅방은 별도로 관리합니다.
- 채팅방 제목·대화·각 스토리 대본을 수정할 수 있습니다. 제목 입력란이 과하게 늘어나던 편집 화면도 수정했습니다.
- ‘지금까지의 대화로 스토리 생성’ 버튼을 입력창 위에 배치했습니다. 버튼은 텍스트에 맞는 크기이며 기존 인연 스토리 버튼과 같은 디자인을 사용합니다.
- 같은 라이브러리 카드를 다시 공개하면 기존 아카이브 게시글을 갱신할 수 있습니다. 좋아요·댓글·조회수·최초 공개일은 유지됩니다.

### 아카이브 서버 운영자 안내

- 공개본 갱신 기능에는 `supabase/migrations/202610240001_community_republish.sql`을 운영 DB에 적용해야 합니다. 앱 릴리즈 워크플로는 DB 마이그레이션을 자동 적용하지 않습니다.
- 라이브러리 수정만으로는 공개본이 변경되지 않습니다. 내용을 확인한 뒤 다시 공개해야 하며, 스토리만 공개를 고르면 기존 공개 채팅도 제거됩니다.
- 공개·업데이트는 합계 하루 5회, 1분 간격 제한이 적용됩니다. 내용이 같은 재요청은 횟수를 차감하지 않습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.4.0_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 17)
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.

### 검증

- 채팅 입력·방 복원·스토리 버튼 위치·이어가기·편집·언어·생성 프롬프트 테스트
- PostgreSQL 마이그레이션·공개본 갱신·권한·중복 요청·반응 보존 테스트
- 튜토리얼·앱 업데이트·플랫폼별 버전 일치 확인
