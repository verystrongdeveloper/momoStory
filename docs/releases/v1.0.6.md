## MomoStory v1.0.6

### 주요 변경 사항

- 앱에 익명 스토리 커뮤니티를 추가했습니다. 라이브러리의 `… → 공개하기`에서 제목·대본·저장된 채팅을 공유하고, 다른 사람의 스토리를 감상할 수 있습니다. 회원가입·닉네임 입력은 없습니다.
- 댓글·좋아요·조회수·좋아요한 스토리 목록·신고·본인 게시글/댓글 삭제를 지원합니다.
- 최신순과 전체 기간·일간·주간·월간·연간 인기순을 지원합니다. 기간별 인기순은 게시일이 아닌 해당 기간에 받은 현재 유효한 좋아요 수로 집계하며, 한국 시간 기준입니다.
- 공개는 익명 사용자당 하루 5개, 댓글은 하루 10개로 제한합니다. 공개 간격은 1분, 댓글 간격은 10초이고 댓글은 공백 포함 300자까지입니다. 삭제해도 당일 작성 횟수는 복구되지 않습니다.
- 공개 전 대본 구조·화자·선택지·명령·에셋·길이를 서버에서 검증합니다. 제목은 100자, 대본과 채팅은 합계 5만 자·UTF-8 200KB까지입니다.
- 대본 편집기에 자동 검사를 추가했습니다. 웹/Windows에서는 오류 줄에 빨간 물결 밑줄을 표시하고, 모바일에서는 오류 목록을 눌러 해당 줄을 선택할 수 있습니다. 오류 번호는 빈 줄을 포함한 원본 기준입니다.
- 대기 명령 `waitSecond : 2`와 `waitSecond = 2`를 모두 허용합니다.
- 스토리 선택지를 누를 때 선택한 채팅 효과음을 재생합니다. 영상 추출도 자동 선택 순간에 같은 소리를 넣으며, 채팅 제외 추출과 사용 안 함·음소거·볼륨 설정도 반영합니다.
- 튜토리얼을 최근 기능을 포함한 12단계로 개편하고 한국어·영어·일본어·중국어로 제공합니다. 기존 사용자에게 강제로 다시 표시하지 않으며 `설정 → 사용 방법`에서 열 수 있습니다.

### 다운로드 및 주의 사항

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.6_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 7)
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요하지만 커뮤니티 감상에는 필요하지 않습니다.
- Android 영상 저장은 APK 전용이며 Expo Go에서는 사용할 수 없습니다.
- 좋아요 목록과 본인 게시물 관리 권한은 기기의 익명 세션에 연결됩니다. 기기 변경·앱 데이터 삭제·브라우저 저장 데이터 삭제 후에는 복구할 수 없습니다.
- 공개하면 저장된 채팅도 다른 사람에게 보입니다. 개인정보나 API 키가 대사에 들어 있지 않은지 반드시 확인해 주세요.
