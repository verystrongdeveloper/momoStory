## MomoStory v1.4.1

- 채팅방 제목과 스토리 대본 제목이 다를 때 정상적인 스토리도 아카이브에 공개하지 못하던 오류를 수정했습니다.
- 공개용 사본의 제목 줄만 게시글 제목에 맞춥니다. 라이브러리의 원본 스토리 제목과 대본은 유지됩니다.
- 라이브러리 카드와 대화 중 생성된 스토리에서 공개하는 경우 모두 적용됩니다.

### 서버 운영 안내

- 이번 신규 공개 오류 수정에는 추가 DB 변경이 필요하지 않습니다.
- 기존 공개 게시글을 다시 공개하여 갱신하는 기능에는 v1.4.0에서 안내한 `supabase/migrations/202610240001_community_republish.sql`의 운영 DB 적용이 별도로 필요합니다. 앱 릴리즈는 DB 마이그레이션을 자동 적용하지 않습니다.

### 검증

- 채팅방 제목 변경, 이전 스토리 선택, 한글 제목 줄 및 서버 공개 검증 회귀 테스트
- 채팅 입력·아카이브·편집 테스트
