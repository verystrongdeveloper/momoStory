## MomoStory v1.4.3

- 일반 대사의 대괄호 문구를 효과 명령으로 오인해 스토리 공개를 막던 검증을 수정했습니다. 생성 시에도 대괄호 문구를 정리해 기존 공개 서버와 호환되도록 했습니다.
- 생성한 스토리를 저장 전에 검증하고, 형식 오류가 있으면 한 번 자동으로 수정을 요청합니다. 수정 후에도 오류가 남으면 저장하지 않고 재시도를 안내합니다.
- 모바일 스토리 수정 화면에서 대본 입력란을 넓혔습니다. 입력 중 부가 정보를 접고 키보드 높이가 중복 적용되는 문제를 수정했으며, 커서 위치 유지와 키보드 닫기 버튼을 추가했습니다.
- 영상 추출은 라이브러리 카드의 메뉴 대신 채팅방 안의 개별 인연스토리 메뉴에서 진행합니다.
- 영상에 포함하는 채팅은 바로 이전 인연스토리 이후부터 선택한 스토리가 생성된 지점까지로 제한했습니다. 첫 스토리는 대화 시작부터 포함하며, 선택한 스토리 이후의 대화는 제외합니다.
