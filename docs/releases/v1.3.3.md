## MomoStory v1.3.3

### 주요 변경 사항

- 학생은 캐릭터 설정에 맞는 `선생` 또는 `선생님`으로, 선생은 학생 이름으로 부르도록 호칭 규칙을 강화했습니다. 대사·선택지·나레이션에서 서로를 `너`로 지칭하는 표현을 줄입니다.
- 히나의 성격·말투·선생님과의 관계 설정을 보완했습니다. 파티와 피아노 연습, 사적인 자리에서의 차분하고 솔직한 반응을 반영했습니다.
- 순한맛·매운맛의 스토리 생성 지침을 조정했습니다.
- 히나와 호시노의 표정 이미지를 다시 확인해 총 18개의 이름을 표정 특징에 맞게 정리하고, 25장 전체의 표정 선택 설명을 추가했습니다.
- 기존 스토리의 옛 표정 이름도 같은 이미지로 연결되며, 새 스토리는 정리된 이름을 사용합니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.3.3_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 16)
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.

### 검증

- 72장 전체의 RGBA 픽셀 해시·해상도 및 기존 표정 이름 호환 검증 통과
- 스토리 프롬프트·생성 결과 검증·선생 모드·생성 언어 테스트 통과
- 커뮤니티 공개·검증·재생 관련 테스트 통과
- 앱 업데이트·버전 표시 테스트 및 플랫폼별 버전 일치 검증 통과
