# 유우카 추가

2026-10-26. 하야세 유우카의 기본 교복 모습을 캐릭터 선택, 일반 채팅, 인연 스토리,
스토리 편집·재생·영상 추출, 공개 스토리 검증과 캐릭터 필터에 연결했다.

사용자가 추가한 PNG 10종을 픽셀 변화 없이 무손실 WebP로 변환해 사용한다.
저장·공개 대본의 `.png` 표정 키는 유지하며 WebP 파일로 매핑한다. 실제 이미지 크기인
687×1024에 맞춰 스프라이트 비율을 수정했다. 프로필은 기본 표정을 얼굴 중심으로
확대하고, 한국어·영어·일본어·중국어 이름과 상태 메시지를 등록했다.
표정 설명에는 웃음, 부끄러움, 충격, 난처함, 두 종류의 삐침과 눈 감음을 구분했다.

## 페르소나 참고

- [Game8의 세미나 프로필](https://game8.jp/blue-archive/655214): 밀레니엄 2학년,
  세미나 회계, 수학·예산 관리 능력, 고민할 때 주판을 사용하는 습관을 확인했다.
- [게임란부의 유우카 인물 해설](https://gameranbu.jp/bluearchive/4d676a7cf597e25e191b):
  성실한 성격과 예산 관리, 노아·코유키 및 아리스와의 관계를 참고했다.

위 자료는 팬 공략 사이트이며 공식 원문을 직접 확인한 것으로 표시하지 않는다.
페르소나의 예시 대사는 원작 인용이 아닌 새 문장이다. 선생에게 쓰는 단정한 존댓말,
책임감과 현실적인 지적, 서툰 호의와 배려를 대화 지침으로 작성했다. 모든 화제를
영수증으로 돌리거나 매번 코유키를 벌주는 반응으로 고정하지 않도록 했다.

## 검증 및 서버 반영

`npm run community:assets`로 공개 검증 에셋과 공유 검증기를 갱신한다.
`npm run test:prompt`, `npm run test:community`, `npm run test:sprites`에서
표정 10종, 4개 언어 화자·선택지, 실제 PNG 크기·투명도, 로컬 PostgreSQL의
공개·필터·상세 조회를 검증한다.

위 세 테스트는 통과했다. `npx tsc --noEmit`은 이번에 수정하지 않은
`StoryAssetPanel.tsx`의 웹 `position: fixed`와 `StoryLibraryList.tsx`의
`dataSet` React Native 타입 오류로 실패했다.

운영 공개 스토리에 반영하려면 `supabase/migrations/202610260001_add_yuuka.sql`을
적용하고 변경된 공유 검증기·에셋을 포함해 `community` Edge Function을 배포해야 한다.
이 작업에서는 마이그레이션과 배포 소스를 준비했으며 운영 DB·함수 배포는 실행하지 않았다.
기존 앱에는 유우카 에셋이 없으므로 앱/웹 빌드도 업데이트해야 한다.
