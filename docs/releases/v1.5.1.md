## MomoStory v1.5.1

- AI 및 대화 설정에 OpenRouter와 Venice를 추가했습니다. 서비스별 본인의 API 키를 저장하고 현재 제공되는 텍스트 모델을 선택해 대화와 스토리 생성에 사용할 수 있습니다.
- OpenRouter의 무료 모델과 무료 라우터를 사용하는 자동 선택에 ‘무료’ 배지를 표시합니다. 무료 모델은 목록에서 먼저 표시하며, 무료 이용 한도와 모델별 API 요금은 각 서비스의 정책을 따릅니다.
- 캐릭터 소속이 이름에 따라 자동 표시됩니다. 이제 대본에는 `호시노 : 대사`처럼 이름만 적으면 됩니다. 기존 소속 괄호 표기도 읽을 수 있으며, 아카이브 감상과 영상 내보내기에도 적용됩니다.
- AI 서비스 선택, API 키 보관, 모델 요금 및 사용 방법 안내를 갱신했습니다.
