# 스프라이트 무손실 WebP 변환

2026-10-26. 남아 있던 코유키 14종·유우카 10종·키쿄 17종의 PNG 스프라이트를
무손실 WebP로 변환했다. 원본과 디코딩한 RGBA 전체를 비교해 투명 픽셀의 RGB까지
같은지 확인하고, 크기가 줄어든 경우에만 원본을 대체했다.

| 캐릭터 | 개수 | PNG 바이트 | WebP 바이트 | 감소율 |
| --- | ---: | ---: | ---: | ---: |
| 코유키 | 14 | 5,259,691 | 2,505,184 | 52.4% |
| 유우카 | 10 | 7,940,125 | 4,121,702 | 48.1% |
| 키쿄 | 17 | 4,192,292 | 2,213,626 | 47.2% |
| 합계 | 41 | 17,392,108 | 8,840,512 | 49.2% |

`constants/eventAssets.ts`와 `constants/characters.ts`의 실제 파일 경로를 변경했다.
생성 프롬프트·저장 대본·공개 검증에서 사용하는 `.png` 표정 키는 그대로 둔다.
배경·프로필 사진·공통 효과 이미지는 캐릭터 스프라이트 변환 대상에 포함하지 않았다.

`scripts/convert-sprites-webp.py`는 캐릭터 이미지 폴더의 PNG를 찾아 변환하고,
기존 검증 기록에 신규 기록을 추가한다. Pillow의 `lossless=True`, `exact=True`,
`method=6`을 사용한다. 원본은 Git 이력에 남아 있으며 최종 번들에는 포함하지 않는다.

전체 113종의 검증 기록은 `scripts/fixtures/sprite-webp.json`에 있다.
`npm run test:sprites`는 Sharp로 다시 디코딩하여 크기와 RGBA SHA-256,
lossless VP8L 인코딩, 프로필 이미지 경로, 기존 대본·공개 검증 호환성을 확인한다.
스프라이트·프롬프트·커뮤니티·영상 연출·영상 에셋 테스트가 통과했다.
