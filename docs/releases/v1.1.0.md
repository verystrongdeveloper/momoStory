## MomoStory v1.1.0

### 주요 변경 사항

- 영상 추출 시 720p 또는 1080p 화질을 선택할 수 있습니다. 가로는 1280×720 / 1920×1080, 세로는 720×1280 / 1080×1920을 지원합니다. 기본값은 720p입니다.
- 1080p에서도 기존 영상의 구도와 글자 배치를 유지하며, 선택한 해상도로 직접 렌더링합니다. 저장 파일 이름에 선택한 화질을 표시합니다.
- 프로필에서 캐릭터를 선택하면 일반 채팅방과 인연 스토리 채팅방 중 하나를 고를 수 있습니다. 두 방의 대화는 분리하여 유지합니다.
- 일반 채팅방은 대화 횟수 제한 없이 이어가며, 인연 스토리 채팅방은 기존처럼 대화 3쌍 후 스토리 생성으로 이어집니다. 설정의 대화 모드 선택은 제거했습니다.
- 호시노의 말투와 성격, 선생님과의 거리감이 자연스럽게 드러나도록 페르소나 프롬프트를 보완했습니다.
- Windows 프로그램에서 최신 버전 다운로드 페이지를 기본 웹 브라우저로 열도록 수정했습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.1.0_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 10)
- 1080p는 생성 시간과 파일 크기가 늘어납니다. 환경에 따라 지원하지 않을 수 있으며, 이 경우 720p로 다시 시도해 주세요. 영상은 최대 10분, 파일 크기는 최대 150MB까지 지원합니다.
- 영상 추출 중에는 앱을 실행 상태로 유지해 주세요. 앱 종료·다른 앱 전환·화면 잠금 후의 추출 지속은 보장하지 않습니다.
- 임시 채팅은 앱 실행 중에만 유지됩니다. 저장한 라이브러리 스토리는 유지됩니다.
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.
