## MomoStory v1.1.1

### 주요 변경 사항

- 설정에서 Gemini 모델을 자동 선택하거나 특정 모델로 지정할 수 있습니다. API에서 텍스트 모델 목록을 불러오며, 목록 새로고침으로 새 모델을 확인할 수 있습니다. 자동 선택은 Flash 계열을 우선하고, 직접 선택하면 해당 모델만 사용합니다. 모델 변경 시 기존 대화는 유지됩니다.
- 영상 추출 대기열을 추가했습니다. 여러 영상을 예약하면 순서대로 생성·저장하며 작업별 진행 상태 확인과 취소가 가능합니다. 완료 알림은 5초 후 페이드아웃하며 사라집니다.
- Android 앱 업데이트 후 이전 영상 렌더러 캐시가 재사용되는 문제를 수정했습니다. 추출 영상에서 채팅 입력 중 말풍선이 빠지는 현상에 대응합니다.
- 라이브러리와 아카이브에 한 페이지당 20개씩 표시하는 페이지네이션을 추가했습니다. 검색·캐릭터·정렬 변경 시 첫 페이지로 돌아가며, 카드가 다음 줄로 밀려 오른쪽에 큰 빈 공간이 생기는 문제를 수정했습니다.
- 라이브러리·아카이브에 캐릭터 필터를 추가하고, 아카이브 새로고침을 아이콘으로 변경했습니다. 카드 제목은 한 줄로 표시하며, 썸네일 배경은 스토리의 첫 배경을 사용합니다. 아카이브 이미지 로딩 표시와 캐릭터 표시도 개선했습니다.
- 모바일 스토리 편집 스크롤, API 키 입력 표시, 먼저 말 걸기 토글을 개선하고 마리의 프로필 소개를 수정했습니다.
- 인연스토리 이동 버튼이 마지막 캐릭터 발화가 끝난 뒤 표시되도록 조정하고, 대화 3쌍 완료 안내 문구를 제거했습니다.
- Windows·Android 앱 내 업데이트 설치 기능을 추가했습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.1.1_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 11)
- 영상 추출 대기열은 앱 실행 중 유지됩니다. 추출 중에는 앱을 실행 상태로 유지해 주세요. 다른 앱 전환·화면 잠금·앱 종료 후의 추출 지속은 보장하지 않습니다.
- Gemini 모델별 요금과 사용 한도는 다를 수 있습니다. 목록에 표시되어도 실제 호출 가능 여부는 Google의 권한·지역·할당량 설정에 따라 달라질 수 있습니다.
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.
