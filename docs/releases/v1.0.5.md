## MomoStory v1.0.5

### 주요 변경 사항

- 채팅 말풍선이 나타날 때 효과음을 재생하며, 영상 추출에도 선택한 소리를 적용합니다.
- 설정에서 효과음 5종과 사용 안 함을 선택하고 미리 들을 수 있습니다. 선택 UI를 간결한 드롭다운 형태로 구성했습니다.
- 영상 추출 시 채팅 포함 또는 스토리만 추출을 선택할 수 있습니다.
- 9:16 화면과 영상에서 감정 아이콘이 캐릭터 머리 옆에 표시되도록 위치를 수정했습니다.
- 새 채팅과 스토리의 이름·학교·부서·제목·대사 등이 선택한 영어·일본어·중국어에 맞춰 생성되도록 규칙을 보완했습니다.
- 스토리 제목 명령은 `타이틀 :`과 `title :`을 모두 지원합니다. 기존 저장본은 자동 번역하지 않습니다.

### 다운로드

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.5_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 6)

Gemini API 키는 포함하지 않습니다. 설치 후 설정에서 본인의 키를 입력해 주세요.
Android 영상 저장은 APK 전용 기능이며 Expo Go에서는 사용할 수 없습니다.
