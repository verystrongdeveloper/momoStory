## MomoStory v1.0.8

### 주요 변경 사항

- 설정에서 `채팅만` 또는 `인연 스토리 포함`을 선택할 수 있습니다. 채팅만 모드에서는 대화 3쌍 제한 없이 계속 대화합니다. 기본값은 기존처럼 인연 스토리 포함입니다.
- 대화 모드를 변경하기 전에 초기화 확인 창을 표시합니다. 확인하면 모든 캐릭터의 임시 채팅·입력 초안·안 읽음 표시와 AI 대화 기억을 초기화하며, 라이브러리에 저장한 스토리는 유지합니다. 설정은 앱 재실행 후에도 유지됩니다.
- 인연 스토리 포함 모드에서는 대화 3쌍이 완성되는 즉시 추가 전송을 막습니다. 스토리를 끝까지 감상하면 해당 캐릭터의 채팅이 자동으로 새로 시작됩니다. 중간에 나가면 생성된 스토리를 다시 열 수 있습니다.
- 영상 추출 옵션과 저장 위치를 정하면 옵션 창이 닫히고, 다른 화면을 사용하면서 추출을 계속할 수 있습니다. 앱 상단의 작은 진행 표시에서 진행률·취소·완료·실패를 확인합니다.
- 추출 영상에서도 캐릭터 메시지가 나오기 전에 1.5초간 입력 중 `···` 말풍선을 표시합니다. 효과음은 메시지가 나타날 때 재생됩니다.
- 공유 스토리의 저장된 채팅 아래에 표시되던 메시지 전송 불가 안내를 없앴습니다.
- 커뮤니티 게시글을 내 라이브러리로 가져올 수 있습니다. 제목·캐릭터·대본·채팅을 함께 저장하며, 같은 게시글의 중복 저장과 기존 수정본 덮어쓰기를 방지합니다.
- 커뮤니티 게시글 카드를 좁은 화면에서는 한 행에 2개, 넓은 화면에서는 3개씩 표시합니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.8_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 9)
- 영상 추출 중에는 앱을 실행 상태로 유지해 주세요. 앱 종료·다른 앱 전환·화면 잠금 후의 추출 지속은 보장하지 않습니다.
- 임시 채팅은 앱 실행 중에만 유지됩니다. 저장된 라이브러리 스토리는 대화 모드 변경으로 삭제되지 않습니다.
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.
