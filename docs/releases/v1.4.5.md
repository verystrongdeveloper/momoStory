## MomoStory v1.4.5

- 유우카와 키쿄를 추가했습니다. 캐릭터 목록에서 선택해 채팅과 인연 스토리를 즐길 수 있습니다. 페르소나, 프로필, 유우카 표정 10종·키쿄 표정 17종과 상황별 표정 설명을 연결했습니다.
- 설정을 항목별 목록으로 정리했습니다. 알림·화면·사운드·AI 및 대화·언어·안내·앱 정보 및 업데이트를 누르면 세부 설정을 조작할 수 있습니다.
- 휴대폰 앱은 기본 세로 고정으로 동작합니다. 설정 → 화면 → 화면 방향에서 세로·가로를 직접 선택하고 자동 저장합니다. 스토리를 열거나 닫아도 선택한 방향을 유지합니다. 이 설정은 Android·iOS 앱에서만 표시됩니다.
- API 키·모델·선생 모드는 설정 → AI 및 대화에서, 사용 방법과 이용 약관은 설정 → 안내에서 확인할 수 있습니다.
- 튜토리얼을 새 설정 구조에 맞춰 4개 언어·14페이지로 갱신했습니다.
- 코유키·유우카·키쿄 스프라이트 41종을 무손실 WebP로 변환했습니다. 원본 픽셀과 투명도를 유지하면서 해당 이미지 용량을 17.39MB에서 8.84MB로 약 49.2% 줄였습니다. 기존 저장·공개 스토리의 표정 이름은 계속 지원합니다.

### 서버 적용 안내

유우카·키쿄 스토리를 운영 아카이브에 공개하려면 다음 마이그레이션을 순서대로 적용하고 변경된 공유 검증기·에셋 목록을 포함한 `community` Edge Function을 배포해야 합니다.

1. `supabase/migrations/202610260001_add_yuuka.sql`
2. `supabase/migrations/202610260002_add_kikyou.sql`

이번 앱 릴리즈 워크플로는 Supabase를 자동 배포하지 않습니다. 기존 앱에서 새 캐릭터의 스토리를 재생하려면 앱 업데이트가 필요합니다.
