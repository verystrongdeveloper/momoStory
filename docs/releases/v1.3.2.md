## MomoStory v1.3.2

### 주요 변경 사항

- 인연스토리 채팅에서 대화 1쌍을 완료하면 새로고침 옆의 `즉시 생성`으로 현재 대화에 기반한 스토리를 만들 수 있습니다. 기존 3쌍 이후 생성 흐름도 유지합니다.
- 편집기에 `스토리 수정`과 `채팅 편집` 탭을 추가했습니다. 메시지 내용·발신자·순서·프로필 표시를 수정하고, 메시지를 추가·삭제할 수 있습니다.
- 아카이브 공개 시 `채팅 + 인연스토리` 또는 `인연스토리만`을 선택할 수 있습니다. 채팅을 제외해 공개해도 내 라이브러리에는 그대로 남습니다.
- 아카이브 감상 버튼을 재생 아이콘으로 바꾸고, 채팅이 없는 게시글은 바로 스토리를 재생하도록 개선했습니다.
- 프로그램·웹에서 숫자키 1~9로 선택지를 고를 수 있습니다. 선택지 왼쪽에 번호를, 대화창의 진행 화살표 위에 `SPACE` 안내를 표시합니다. 모바일 앱에는 키보드 안내를 표시하지 않습니다.
- 첫 선택지의 글씨체가 깜빡이며 바뀌는 문제를 수정했습니다.
- 캐릭터 스프라이트 72장을 무손실 WebP로 변환했습니다. 원본 픽셀·해상도·투명도를 유지하면서 이미지 총용량을 약 61.6MB에서 30.7MB로 50.2% 줄였습니다. 기존 스토리의 PNG·JPG 이름도 계속 지원합니다.
- 한국어·영어·일본어·중국어 안내와 튜토리얼을 갱신했습니다.

### 다운로드 및 안내

- Windows: `MomoStory.exe` 또는 `MomoStory_1.3.2_x64-setup.exe`
- Android: `MomoStory.apk` (versionCode 15)
- Gemini API 키는 포함하지 않습니다. 새 대화·스토리 생성에는 본인의 키가 필요합니다.

### 검증

- 72장 전체의 RGBA 픽셀 해시·해상도·기존 스토리 이름 호환 검증
- 채팅 입력·즉시 생성, 편집기, 아카이브 공개·재생, 튜토리얼 관련 테스트 통과
- 영상 타임라인·인코딩 로직·연출·에셋·추출 UI 테스트 통과
- 웹 프로덕션 빌드 통과
