# 호시노 페르소나 조사·수정 근거

확인일: 2026-10-20. 대상은 기본 모습의 3학년 호시노다. 과거 학년이나 다른 의상의 연출을 기본 성격으로 섞지 않는다.

## 참고 자료

- [공식 애니메이션 캐릭터 소개](https://sh-anime.shochiku.co.jp/bluearchive-anime/character/takanashi-hoshino/): 3학년, 전 학생회 부회장, 현 대책위원회 위원장. 낮잠·빈둥거리기를 좋아하고 평소에는 일을 미루지만 동료를 지키려고 최전선에서 싸운다는 설명을 확인했다. 기존의 ‘전 학생회장’과 ‘임시 위원장’ 표기를 수정했다.
- [게임 보이스 전사·번역 모음](https://bluearchive.fandom.com/wiki/Takanashi_Hoshino/Audio): 로그인·로비·인연 랭크·메모리얼 로비 항목 참고. 공식 설명 페이지가 아닌 팬 정리 자료이며, 한국어 공식 대사를 검증한 자료로 취급하지 않는다. 로비에서는 상대의 수고를 알아보고 휴식을 권하며, 자신이 필요하다는 말이 진심이면 머뭇거리며 감사한다. 메모리얼에서는 수족관을 즐기면서 자신만 즐거워해도 되는지 망설인다.
- [일본어 보이스 전사 모음](https://scrapbox.io/aosakaao12/%E3%83%9B%E3%82%B7%E3%83%8E%E3%83%9C%E3%82%A4%E3%82%B9%E4%B8%80%E8%A6%A7): 팬 전사 자료. 로비·인연·전투 대사에서 자기 지칭이 항상 ‘아저씨’로 고정되지 않고, 전투에서는 짧고 분명한 표현을 사용한다는 점을 교차 확인했다. 별표가 붙은 미확인 전사는 근거에서 제외했다.

## 프롬프트로 옮긴 판단

- ‘항상 나른하게’, ‘자기 지칭은 아저씨’, ‘한 문장 50자’라는 고정을 풀었다. 느긋함은 기본이지만 관심·칭찬·위험에 따라 말의 속도와 온도가 달라지도록 했다.
- 낮잠을 좋아하는 일상, 수족관에서의 들뜸, 동료를 지키는 판단을 함께 넣었다. 관심사를 매 대화에 억지로 끼워 넣지는 않는다.
- ‘절대적 신뢰’와 ‘아슬아슬한 장난’ 대신 대화 맥락에 맞는 친근함, 염려, 칭찬을 받을 때의 서투름으로 구체화했다. 이는 대사의 대비를 대화 생성 지침으로 해석한 것이며 공식 문구가 아니다.
- 과거의 상실감은 배경으로 두고 매 답변의 주제로 만들지 않는다. 인연 대사의 감정도 매번 같은 강도로 표현하지 않는다.
- 프롬프트의 한국어 예시는 이번에 작성한 창작 예시다. 원작 대사나 공식 번역을 인용한 문장이 아니다.

## 적용 경로와 확인

`shared/prompts/personas.js`의 호시노 항목을 채팅 조립기와 인연스토리 조립기가 함께 사용한다. Express도 동일한 공유 모듈을 사용한다. 다른 학생의 페르소나는 수정하지 않았다.

품질 확인용 대화: 평범한 인사 / 진심 어린 칭찬 / 수족관 제안 / 업무 도움 요청 / 선생이 위험에 처한 상황 / 힘든 과거를 직접 묻는 상황. 각각 인사 추임새의 반복, 무조건적인 졸림, 과도한 유혹·비극, 불필요한 지문이 생기는지 살펴본다. 조립 테스트만으로 실제 모델의 말투 품질을 보장하지 않으며, 유료 모델 호출을 통한 비교 평가는 이번 수정에 포함하지 않았다.
