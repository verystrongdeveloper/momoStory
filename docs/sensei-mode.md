# 선생 모드

설정의 선생 모드에서 순한맛(기본)과 매운맛을 고른다. 설정은 이 기기에 자동 저장되며 다음 스토리 생성부터 적용한다.

- 순한맛: 배려와 부드러운 유머를 중심으로, 가벼운 장난에서 다정한 선택지와 도움을 주는 행동으로 이어 간다.
- 매운맛: 사용자의 최근 채팅에 드러난 말투·장난기·엉뚱한 발상·호불호를 이야기의 선택지·행동·1인칭 나레이션에 반영한다. 능청스럽게 맞받아치고 장난을 실제로 이어 가는 선택지를 만들며, 캐릭터의 당황과 반격도 사건으로 발전시킨다. 맥락 없는 사과나 농담 취소로 성격을 바꾸는 전개를 줄인다. 차분한 사용자를 억지로 거칠게 만들지 않는다.

예를 들어 같은 도넛 실종 이야기도 순한맛은 함께 찾고 쉬는 방향으로,
매운맛은 선생이 용의자를 자처하며 엉뚱한 탐정 놀이를 이어 가는 방향으로 구분한다.
예시는 구조 참고용이며 생성할 때마다 그대로 반복하지 않는다.

캐릭터의 성격과 거절 의사는 두 모드에서 모두 유지한다. 실제 잘못에 대한 자연스러운 사과는 가능하다. 성적 수위를 높이거나 학생의 성적 묘사를 허용하는 설정은 아니다.

직접 호출과 Express 모두 생성 요청이 시작될 때 모드를 고정하여 인물 선정·시놉시스 작성과 대본 생성 두 단계에 동일하게 사용한다. 진행 중인 생성, 저장된 대본, 재생·공개에는 소급 적용하지 않는다. 공개 데이터 구조나 서버 에셋 허용 목록은 바뀌지 않는다. Gemini 생성 결과는 비결정적이므로 모든 문장에서 특정 행동을 보장하지 않는다.

검증: `npm run test:sensei-mode`, `npm run test:prompt`, `npm run test:language`, `node scripts/test-settings-version.cjs`. API 호출은 모의 처리한다.
